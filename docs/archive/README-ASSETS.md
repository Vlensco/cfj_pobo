Arsip ini berisi foto visual yang direferensikan oleh storefront TERRACE. File mempertahankan nama storage asli agar mudah dicocokkan dengan kode katalog.

Catatan teknis: URL storage storefront memakai ekstensi `.jpg`, tetapi file yang dikembalikan storage terdeteksi sebagai WebP. Browser tetap dapat merendernya melalui URL yang sekarang digunakan aplikasi. Jangan mengganti ekstensi pada kode storefront tanpa memperbarui URL dan checkpoint terkait.

Foto-foto ini adalah asset yang dipakai oleh project TERRACE saat ini. Arsip source code terpisah tidak menyertakannya karena media dikelola di storage asset agar proses deployment tidak membawa file binary besar ke repository.
