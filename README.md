# CFJ Storefront

Classic football shirt storefront: React + Vite client, Express + tRPC server, PostgreSQL via Drizzle.

## Project layout

```
client/                 React storefront and admin (Vite)
  public/manus-storage/   product photos served at /manus-storage/*
  src/
    components/           UI, incl. personaliser, bag, order views
    pages/                routes
    i18n/                 EN / ID / ZH translation tables
server/
  _core/                  server plumbing: entry points, Express app, tRPC, auth, env
  db/                     database access, one file per domain (re-exported by index.ts)
  routers/                tRPC routers; index.ts builds the appRouter
  modules/
    catalog/              CSV catalog, store prices, patch / nameset add-ons by SKU
    orders/               order requests, tracking, admin metrics
    payments/             Wise (bank transfer), NOWPayments (crypto), Stripe, exchange rates
    followUp/             follow-up reminders for unanswered order requests
    uploads/              font reference uploads for custom namesets
  scripts/                one-off scripts (init DB, import CSV)
shared/                   types and helpers used by both client and server
drizzle/
  schema.ts               database schema (source of truth)
  manual/                 hand-written, additive SQL migrations
Database/                 Shopify CSV exports (customer/order CSVs are git-ignored)
docs/                     product docs; docs/archive holds old notes
api/index.js              Vercel serverless bundle (generated by `pnpm build`)
```

## Getting started

```bash
pnpm install
cp .env.example .env          # fill in DATABASE_URL, JWT_SECRET, WISE_API_TOKEN, ...
pnpm db:init                  # optional: create the local role + database
pnpm db:import                # load products, customers and orders from Database/*.csv
pnpm dev                      # http://localhost:3000
```

Restart `pnpm dev` after changing `.env`; environment variables are read at startup.

## Database changes

Edit `drizzle/schema.ts`, then add an additive SQL file to `drizzle/manual/` and apply it:

```bash
psql "$DATABASE_URL" -f drizzle/manual/<file>.sql
```

Do not run `pnpm db:push` against PostgreSQL 18: drizzle-kit misreads its named
NOT NULL constraints and tries to drop every one of them. It works on the
PostgreSQL 14 server.

## Payments

- **Wise**: Wise has no hosted checkout, so customers pay by bank transfer to the
  shop's Wise account. Checkout converts the IDR total with Wise's live rate and
  shows the account details plus an order reference (`TR-WS-…`). Confirm the
  payment in Wise, then mark the order as paid in the admin dashboard.
  Env: `WISE_API_TOKEN`, `WISE_ENV` (`sandbox` | `production`), `WISE_CURRENCIES`.
- **NOWPayments**: crypto invoices (BTC / USDT) with an IPN webhook at `/api/nowpayments/webhook`.

Every checkout requires a signed-in customer account, and the bag is validated
against the catalog before payment is allowed.

## Scripts

| Command | What it does |
| --- | --- |
| `pnpm dev` | Dev server with Vite middleware and auto-restart |
| `pnpm test` | Vitest (server + client) |
| `pnpm check` | TypeScript type check |
| `pnpm build` | Client build + Vercel serverless bundle (`api/index.js`) |
| `pnpm build:vps` | Client build + Node server bundle (`dist/index.js`) for the VPS |
| `pnpm db:import` | Import the CSV exports in `Database/` |
